# Арсенал дуэлянта (PVP20)

Fabric-мод для Minecraft **26.2** с **24 предметами**: исходные 8 оружий и 12 активных способностей плюс полный комплект усиленной алмазной брони. Все предметы собраны во вкладке творческого режима **«Арсенал дуэлянта»**; у них есть имена и описания на русском и английском. Оружие и способности используют отдельные пиксельные иконки, броня — ванильные алмазные иконки и текстуру на модели игрока.

Усиленный комплект даёт **24 очка брони** (алмазный — 20); каждая часть добавляет 3 прочности брони и 0,1 сопротивления отбрасыванию. Долговечность каждой части выше алмазной, ремонтируется алмазами. Иконки и внешний вид надетой брони намеренно используют ванильные алмазные текстуры. Оружие изнашивается как обычное алмазное оружие. Активные предметы не расходуются — повторное использование ограничено персональной перезарядкой. Эффекты по области не задевают союзников.

## Сборка

Нужны **JDK 25**, Fabric Loader **0.19.5** и Fabric API **0.161.0+26.2**.

```bash
./gradlew build
```

Готовый мод появится в `build/libs/pvp20-1.0.0.jar`. Установите этот JAR и Fabric API в папку `mods` профиля Minecraft 26.2.

Для разработки: `./gradlew runClient`.

## Команды и тайник

Вкладка творческого инвентаря называется **«Арсенал дуэлянта»**. Для быстрого тестирования добавлены команды (требуются права оператора/включённые читы):

```text
/pvp20 give all                  # выдать все 24 предмета
/pvp20 give emberfang_blade      # выдать один предмет; ID подсказываются Tab
/pvp20 stash                     # построить тайник впереди игрока
```

`/pvp20 stash` создаёт подземный бункер из глубинного сланца примерно в пяти блоках перед игроком. Внутри есть освещение, лестничный проход с люком на поверхности и сундук со всеми 24 предметами. Команда изменяет блоки вокруг места постройки, поэтому используйте её в подходящем месте. Координаты входного люка выводятся в чат.

Обычная команда Minecraft `/give` тоже работает, например:

```text
/give @s pvp20:emberfang_blade
/give @s pvp20:smoke_bomb
```

## Ресурсы

Пиксельные иконки и JSON-модели хранятся в `src/main/resources/assets/pvp20`. Их можно пересоздать командой `python3 scripts/generate_assets.py` — скрипт использует только стандартную библиотеку Python.
